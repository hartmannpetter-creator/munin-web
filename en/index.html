The problem

A fault code comes too late.

Fault code

Logged once the deviation has already happened.

It tells you something is wrong, not that something is about to go wrong. You get a number and a generic explanation, but not the context, not the history, and not the direction the condition is moving in.

Munin

Catches the degradation while it is still a warning.

Follows the condition while it is still within normal range, and sees the pattern drift early, in pressure, airflow and temperature. While maintenance can still be planned, not urgent.

How

Three steps, from healthy state to risk.

Munin works in sequence: it learns what is normal for the machine, sees when the condition degrades, and assesses what that means going forward. One clear conclusion instead of a stream of numbers.

01

Healthy state

Over weeks and months, builds a picture of how this particular machine behaves when it is healthy. Nothing is preset; everything is learned from the machine itself.

02

Degradation

When the pattern starts to drift, Munin sees it in context. Not as a single spike, but as a condition in change.

03

Risk

Assesses what the change means going forward, and gives one clear conclusion you can plan maintenance around, not the noise behind it.

What Munin promises

Silence is better than a false alarm. Munin speaks up when it is confident, not to fill the screen.

The system suggests. The human decides. You always have the final say.

Under the hood

Built to run in the car, not in the cloud.

Live signals through the car's nervous system. Read, never controlled.

Hardware

Jetson Orin Nano Super

AI workloads run on an Ampere GPU with tensor cores, 67 TOPS. Learning and analysis happen locally, on the device.

Data source

OBD-II today, passive observer

The data is raw material, not the goal. The architecture is source-agnostic; the value lies in what the system learns from it over time. Munin never sends commands to the machine.

Where it happens

On-board learning, deep analysis by Hugin

Continuous learning of the machine's healthy state runs locally on the device. When a thorough assessment is needed, selected data is sent to a more powerful reasoning layer.

Approach

Self-learning, not hard-coded

Instead of fixed thresholds, Munin builds its own understanding of what is normal for each individual machine.
